# 网页与思维导图分享：登录可见候选

基线 f0b94dcb；独立候选，不并入11-11画廊两站发布。两站共用实现，本站全部有效登录用户可查看；组管理员只管理本组role=user的作品，超级管理员全局。无机器预审、白名单、口令或新角色。

## 行为

- `/pages/:userId/:slug`旧地址只302到`/shared-pages/...`，不返回HTML内容；前端两种路径均有登录守卫。内容API有现有JWT/账号状态验证及private,no-store。作品在不带allow-same-origin的sandbox iframe运行，不能读站点登录存储或覆盖举报按钮。
- 思维导图分享API同时验证登录、share_state和HMAC。迁移前记录按可能已分享处理，revision=0与旧HMAC完全兼容；不能从旧库区分“发过链接”和“从未复制过链接”。新保存默认draft，点击分享才published。撤回变withdrawn并增加revision；重新分享生成新令牌，旧令牌不会恢复。
- HTML沿用is_published/published_at/version；内容保存不能改发布标记。发布/作者取消发布带版本且与积分记账同事务，0积分配置正常；新撤回接口不动积分。重新发布沿用已有发布计费规则，不承诺免发布费用。
- 后台在图片/视频审核相邻增加“网页与思维导图”，复用画廊scope和groups，支持班级筛选、已撤回记录、单击撤回。超级管理员可筛待处理举报、查看无举报人身份的原因、撤回或标记已处理。举报不自动隐藏、不新增先审后发。

## 迁移与回退

本候选依赖画廊基线，适用Oracle MySQL >=8.0.16（两站既有前检8.0.46、8.0.43不替代上线时核验）。新增单张`20261111_001_shared_work_visibility.js`：思维导图share_state/share_revision，shared_work_reports/shared_work_events。无内容删除、积分变更、OSS操作。采用MySQL可重入DDL检查；应用切换前必须迁移完成，不能混跑未知旧应用写者。未来发布卡需将此精确迁移纳入原生工具清单和审核，不直接用画廊六张清单跑它。

`down`只允许未使用的新安装：举报/审计为空、无draft或withdrawn记录时才撤销结构，已在有原数据场景演练up/down/up。发生分享/撤回/举报后down明确拒绝，保留状态与审计。运行过本候选后**不能直接退到匿名可访问的父版**；须保留此候选登录与撤回门的兼容回退版，或先在站点入口停用两类分享/发布接口再切旧应用，保持关闭直到修复。该兼容回退产物/入口停用方案须在另行发布卡具体绑定并批准，本开发卡不声称已经就绪，也不执行生产回退。
