# AI训练专区 预置数据包

每个子目录一个包，manifest.json 描述类别、文件/行与许可证。图像包的换条件集由平台在原图上合成。

**区分度要求**（2026-09-14 起）：同一类里的样本必须真的不一样（不同个体/品种/角度/背景），否则留出集只是训练集的复制品，测出来永远 100%，学习曲线、错标实验都没有意义。
验证方法见 scratchpad 的 pack-eval（留一法、3/10/30 张学习曲线、各换条件集、5 折错标 20%/40%），当前数值：

| 包 | 留一法 | 学习曲线 3/10/30 张 | 换条件集 | 错标 20% / 40% 后 |
|---|---|---|---|---|
| flowers | 72% | 55% / 68% / 78% | 模糊 48%、暗光 80%、局部放大 78% | 69% / 54%（干净 73%） |
| fruits-varied | 99% | 78% / 91% / 90% | 换品种 55%、彩色背景 94%、深色背景 85% | 95% / 85%（干净 98%） |
| shapes | 100% | 74% / 94% / 100% | 深色背景 96%、花纹背景 83%、手绘 63% | 100% / 100% |
| sounds-synth | 98% | 86% / 95% / — | 叠加噪声 97%、换音色 69%、换设备 94% | 97% / 82%（干净 98%） |

flowers 是"真实数据"的那一个：留出集会有真正的错误，多少张够用（L4）与喂错数据（L3）默认用它；shapes / sounds-synth 是没有摄像头、麦克风时的兜底，仍然偏容易。
