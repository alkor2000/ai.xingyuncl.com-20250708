# 网站作品功能 · 人工测试单（给同事，非程序验收）

这一份是**普通同事按步骤点一遍**用的。程序化验收（脚本、屏障、单测）另有档案，不在这里。
**所有结论都待真人验证**：下面每条的"预期"是实现时的设计意图，不是已经有人验过的结论。

## 1 打开网页编辑器，确认入口存在

- **准备**：用学生 A 登录测试环境，进入「网页编辑器」。
- **点击**：随便打开一个自己的项目。
- **预期**：页面里（项目/页面列表下方）出现「教学任务作品」这一块。如果它说「从 edu 的作业进入本页面后，这里会出现…」，说明缺少任务上下文，这是正常的。
- **失败的样子**：整块不出现（可能是功能没开），或出现报错红条。

## 2 从教学任务进入，关联自己的项目

- **准备**：请 edu 侧同事给一条"打开编辑器"的链接（它带一段只在浏览器地址栏片段里的任务信息）。
- **点击**：用这条链接打开编辑器 → 选一个**自己的**项目 → 「关联到本次教学任务」→ 选入口页面 → 确认。
- **预期**：面板显示已关联、作业编号、入口页面；地址栏里那段任务信息**自动消失**（不应留在地址栏）。
- **再试**：拿同一条链接再关联一次 → 应当被拒绝（这条信息只能用一次）。

## 3 "真正保存"才算制作中

- **准备**：接着上一条，作品刚关联时，状态应当是「已关联 · 还没有有效保存」。
- **点击**：在编辑器里改几个字 → 点「保存」（会扣积分）→ 回到面板（可刷新页面）。
- **预期**：状态变成「可预览」/「制作中」，「制作事实」显示保存时间。
- **反例（重要）**：只把页面**改个名字**、或只是打开了默认项目让系统自动建了一个空白页——这些都**不应该**让状态变成制作中。
- **老项目**：关联一个很久以前做的旧项目，状态可能显示「制作情况未知」并说明原因。**这不是"未开始"**，也不是错误。

## 4 生成评阅版本，并确认它不会跟着改稿变

- **点击**：面板里「生成评阅版本」。
- **预期**：出现「第 1 版」和时间。连点两次也只应生成一版。
- **再点击**：回到编辑器，把页面内容**大改一遍**并保存；再点「打开最新评阅版本」。
- **预期**：打开的仍然是**改稿之前**的样子。改稿不会污染已经固定的版本。

## 5 图片仍然看得见

- **准备（按这个真实路径走，编辑器里没有"上传图片"按钮）**：
  1. 打开平台的**对话**，在输入框里上传一张自己的图片（也可以用 AI 图像生成一张）。
  2. 在对话里**右键那张图 → 复制图片地址**（形如 `https://<平台域名>/uploads/chat-images/2026-09/xxxx.png`）。
  3. 回到网页编辑器，在 HTML 里写一行 `<img src="粘贴的地址">`，点**保存**。
- **点击**：生成一个新的评阅版本 → 打开它。
- **预期**：图片**显示**出来。
- **再试（关键）**：把原图删掉（或换成别的图）并保存页面 → 再打开**刚才那一版**评阅版本 → 图片**仍然显示**，页面仍是旧样子。
- **反例**：把**别人**上传的图片地址粘到自己的页面里 → 生成评阅版本 → 那张图**显示不出来**（平台不会把别人的文件复制进你的版本）。站外图片（别人网站上的图）也不会被固定，打开时可能是空的。把地址故意改一个字母（例如把 `axb.png` 写成 `a_b.png`）同样**不会**显示成别的图。

## 6 没有资格的人看不到

- **准备**：请 edu 侧同事发一个"教师评阅入口"链接；另外准备一个**没有资格**的人（例如别班老师或另一个学生账号）。
- **点击**：① 有资格的老师打开链接 → 应当能看到作品；② 把**同一条链接**转发给第二个人打开 → 应当打不开（入口只能用一次）；③ 请没有资格的人索要新链接 → 应当**发不出来**或打不开。
- **预期**：作品在一个**单独的预览域名**上打开，不是平台主域名。
- **注意**：如果测试环境**没有接 edu 的资格核验**，第 ③ 步会直接被系统拒绝（提示本站点尚未接入评阅资格核验）——**这是正确行为**，请照此记录。

## 7 「未同步」不是「未开始」

- **准备**：这条需要后端同事配合制造一次"刚保存、还没同步完"的瞬间（或在弱网下连点保存）。
- **预期**：edu 看到的数据里，这份作品是「还没同步完」，**不会**被显示成「未开始」。
- **失败的样子**：作品明明刚保存过，却在名单里显示成"未开始"。

## 8 取消关联

- **点击**：面板里「取消关联」。
- **预期**：老师无法再打开这份作品；**已经生成的评阅版本仍然保留**；项目和页面**不会被删除**。

---

## 9 老师那边看到的是**作品的名字**

- **准备**：学生 A 已经按第 2、3 组关联过并且**真正保存**过一次。
- **看**：edu 那边的作品列表里这件作品显示的名字。**edu 界面目前还没有**，所以这一组要么由后端同事读一次"当前状态"把名字念出来，要么整组标注为"暂不能在正式 edu 测"。
- **预期**：显示的就是学生在网页编辑器里给这个项目起的名字，一字不差；不是编号、不是页面标题、也不是"未命名作品"。
- **再做一次**：学生把项目**改名** → 老师这边刷新 → 名字跟着变成新的。（改名仍然**不算**"真正保存"，第 3 组的结论不变。）
- **再做一次**：学生把这个项目**删掉** → 这件作品变成"已不可用"，**名字位置显示明示回退**（例如"未命名作品"），**不显示**删之前的旧名字。
- **失败的样子**：名字位置空白或显示一串编号；改名之后老师这边还是旧名字；作品删了之后名字还挂在那儿；或者别的学校/别的班的老师能看见这件作品的名字（第 6 组已经覆盖看不看得见，这里只多看一眼名字）。
