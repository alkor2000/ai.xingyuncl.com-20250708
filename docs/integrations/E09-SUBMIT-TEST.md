# 普通同事测试单：学生在编辑器里交作业

> **口径（2026-09-24）**：这条交作业通道的代码刚写好，**默认是关着的**，正式站上没有、也不会自己出现。
> 要跑这张单子，得先请技术同事在**测试环境**打开 P09 开关、配好"老师那边"的提交地址；
> 跑完请让他关回去。看不到下面说的按钮，先问是不是没开——**那不是缺陷**。

这张单子给不写代码的同事用：只用浏览器，不碰服务器、不改配置。要看的就一件事——
**学生做完网页，能不能在同一个地方把作业交上去，交上和没交上说的是不是人话。**

## 开始之前

- 一台电脑 + 一部手机（或把浏览器窗口拉到手机那么窄；两种宽度都要看）。
- 一个**测试用**学生账号，和一份老师那边已经布置好的作业（带课次编号）。不要用真实学生账号。
- 每步记**你看到了什么**（截图最好），不要只记"对/不对"。

## 一、按钮在不在它该在的地方

1. 用测试学生账号进网页编辑器，打开自己的作品。
2. 右侧应该有"教学任务作品"面板，显示这次作业的课次和作品名。
3. 面板上**最显眼的那个按钮是「交作业」**；旁边一行小字："做完就在这里点「交作业」，不用回 edu 再点一次。"
4. "取消关联"应该在下面一行，是**小号的红字**，不像个可以随便点的按钮。
5. 拉窄到手机宽度再看一次：按钮还在，文字没被切、没有横向滚动条。

记录：□ 两种宽度都看到「交作业」 □ 取消关联是小号红字 □ 位置不对（写下看到了什么）

## 二、正常交一次

6. 随便改一点内容，**保存**。
7. 点「交作业」，等一两秒。
8. 应该出现一个绿框：**"已交 · 第 N 版 · 时间"**，底下一句"老师看到的就是这一版；你之后再改稿，不会覆盖它。"
9. 请对接同事在老师那边确认：**收到的就是第 N 版、同一个时间**。

记录：□ 绿框出现，N = ____，时间 = ____ □ 老师那边对得上 □ 对不上（两边都截图）

> 交上的版本是**老师那边**定的，不是这边算的。第 N 版的 N 由老师那边给，这边只照抄。

## 三、再点一次、连着点两下

10. 再点一次「交作业」。按作业规则，这里可能是"又交了一版"，也可能是"次数用完了"——
    **只要提示是人话、并且和老师那边一致，就算对。**
11. 快速连点两下：**不应该**出现两条提交记录。请对接同事在老师那边数一下。

记录：□ 提示 = ____________ □ 老师那边只多了一条 □ 多了两条（请立刻记下时间）

## 四、交不上的时候，话说清楚没有

请对接同事在老师那边分别造出下面几种情况，每种点一次「交作业」：

| 情况 | 学生应该看到 | 绝不能看到 |
| --- | --- | --- |
| 过了截止时间 | 黄/红框写明"已过截止时间…"（老师那边的原话） | 绿色"已交" |
| 次数用完 | "提交次数已经用完了" | 绿色"已交" |
| 作业已结束 | "本次作业已结束" | 绿色"已交" |
| 不在名单里 | "这个账号不在本次作业的名单里" | 绿色"已交" |
| 还没保存过 | "还没有可以提交的保存版本，请先保存一次" | 绿色"已交" |
| 老师那边连不上（拔网线/停服务） | "没有交上：这次没有拿到老师那边的答复，请稍后再试" | 绿色"已交"，也不该一直转圈不给话 |

记录：每行写下**你看到的原句**。任何一次出现绿色"已交"而老师那边其实没收到，**立刻停下并记下时间**——
这是本轮最要紧的缺陷。

## 五、"先保存后关联"这一种

12. 换一份**先保存过、之后才关联**这次作业的作品。
13. 面板上应该有一句提示：**"本次作业还需要在关联之后再保存一次…"**。
14. 按它说的再保存一次，然后交作业——应该能交上。
15. 注意：**不要**用"取消关联"当重试。点它之前会弹确认，写着"这次关联记下的保存证据也会清零"。

记录：□ 提示出现 □ 再保存一次后能交上 □ 取消关联有上面那句确认

## 六、关掉之后

16. 请技术同事把开关关回去，学生刷新页面。
17. "教学任务作品"面板应该**整块消失**，老师那边也不该再收到任何调用。

记录：□ 面板消失 □ 还在（写下看到的）

## 已知不在本轮范围

- 编辑器保存本身偶发的 500（另有反馈单跟进），不是这条通道的事。
- 从作业页一次点进来就直落编辑器：**还没做**，现在学生可能要在 edu 那边多点一次。
- 老师端的评阅、打分、提交列表样式：老师那边的事，这张单子只到"交上了/没交上"。
